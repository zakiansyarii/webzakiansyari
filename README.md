# Zaki Ansyari — Premium Personal Portfolio

Website statis responsif tema hitam, emas, dan putih. Fitur: profil interaktif, keahlian, proyek, timeline, sertifikat/CV, galeri, musik, buku tamu dengan moderasi, statistik kunjungan sederhana, formulir kontak, live chat admin, kartu kontak digital, dan dashboard privat dengan Google Sign-In. Data disimpan di Google Sheets melalui Google Apps Script.

Mulai dari `PANDUAN-DEPLOY-LENGKAP.md`. Ganti placeholder konfigurasi sebelum deploy. Login admin memerlukan OAuth Client ID dan email yang diizinkan.
